Joguinho (Cannon Game)

Jogo de canhão para Android desenvolvido na disciplina de Programação III, baseado no Capítulo 6 de Android 6 for Programmers: An App-Driven Approach (3ª ed.).

Integrantes
Gustavo Amaral Silva
Maria Olivia Cassucci
Objetivo

Praticar animação quadro a quadro, Canvas/Paint, SurfaceView/SurfaceHolder, threads (game loop), sons, eventos de toque e modo imersivo.

Como executar
Clone o repositório e abra no Android Studio.
Aguarde o sync do Gradle.
Execute (▶) em um emulador ou celular com Android 7.0 (API 24) ou superior.
Como jogar

Toque na tela para mirar e atirar. Acerte os 7 alvos antes que o tempo acabe: cada alvo dá +3 s e bater no bloqueador vermelho tira 2 s.

Funcionalidades
Animação manual com game loop em thread própria
Desenho com Canvas e Paint em SurfaceView
Detecção de colisão (círculo x retângulo)
Sons com SoundPool
Modo imersivo (tela cheia)
Diálogo de fim de jogo com reinício
